LiteSpeed static demo

You are looking at a page that ships inside the GitHub Pages frontend. It was not fetched by a proxy: GitHub Pages can only serve static files, so it cannot fetch or rewrite other sites by itself.

What is real here

  • The interface: address bar, history, settings, progress indicator and status pill.
  • The backend discovery and health check shown in the status pill and the Connection panel.
  • The URL codec, which runs live on the URL rewriting page.

What needs the backend

Loading example.com or any other real site. Deploy the API (see the README) and point this frontend at it; the same address bar then loads real pages through /p/{key}/… and this banner disappears.
