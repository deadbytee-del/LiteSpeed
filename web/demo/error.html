Error handling

When an upstream fails, the backend returns a real HTTP status with a stable error code. Navigations get a small HTML page; scripted requests get JSON. This table lists what the backend can return.

StatusCodeMeaning
400invalid_urlThe address could not be parsed
403private_targetLoopback/private address refused (SSRF protection)
502dns_failureHost name did not resolve
502connection_refusedUpstream refused the connection
504upstream_timeoutNo response headers within the timeout

Example JSON

{
  "error": {
    "status": 504,
    "code": "upstream_timeout",
    "message": "The upstream server took too long to respond.",
    "target": "https://slow.example/"
  }
}
